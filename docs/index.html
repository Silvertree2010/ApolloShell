ApolloShell

A clean, minimalist desktop shell featuring a sidebar, app launcher, dashboard, and control center, inspired by Caelestia Dots.

Download for macOS .dmg
$ brew trust --tap Silvertree2010/apolloshell$ brew tap Silvertree2010/apolloshell$ brew install apolloshell

Everything where you need it.

Quickly launch apps, check your calendar, control media, monitor system performance, and access essential controls without leaving what you're doing.

Build it your way.

Arrange your panels with the Bento Box editor, then make them yours with simple CSS. Change colours, spacing, shapes, icons, and more without digging through complicated configuration files.
